# GOT RIDER — RULE THE ROAD

3D endless traffic racer with bikes and cars (React Native + Expo SDK 58 + three.js 0.162). Tilt-only steering.

## Run
```
npm install
npx expo install --fix
npx expo start -c
```
`expo-speech` (challenge voice) is in package.json; `expo install --fix` pins the right SDK version.

## Controls
- Tilt phone = steer (angle at START tap = straight). Tap = boost, swipe down = brake.
- Car mode (landscape): GAS / BRAKE / REVERSE / BOOST pads + tilt steering.
- If a phone has no tilt sensor, on-screen LEFT/RIGHT buttons are used.

## Game systems
- 17 vehicles (Lv 1–35), endless levels with ranks + level-up credit bonus.
- 3 rolling missions (get harder every 3 completions), per-vehicle targets.
- Impossible Challenge: one-run hard task, taunting Hindi voice (device TTS, can be turned off).
- `ALL_IMPOSSIBLE` flag in App.js: set `true` to make all normal missions 4x harder.

## Traffic & obstacles
- New traffic: police cars and ambulances (flashing lights, faster), auto-rickshaws (slow).
- Siren plays when a police car / ambulance spawns; near-missing one gives +100 (EMERGENCY NEAR MISS).
- Game modes (Garage tab and READY screen): CLASSIC = traffic only (default). HAZARD = also road cones (light hit, no fall) and work barriers (heavy hit, "ROAD WORK AHEAD!"), score and credits x1.25.

## Garage
- Tabs: GARAGE / MISSIONS / SETTINGS. Swap vehicles with the ‹ › arrows on the preview, or pick from the list.

## Sound
- `sound.js` (expo-audio) + generated WAVs in `assets/sounds/`: per-vehicle engine loops (pitch follows speed), tyre screech, crash, crowd gasp, body thud, near-miss, coin, boost, level-up, music.
- User controls: Settings (main menu and Garage) > All sound, Music, Engine, Effects, Challenge voice; SOUND button on the Pause and READY screens.
- Crash: bike / cycle riders are thrown off, lie on the road, then get back on if HP is left; bystanders shout (device Hindi voice).

## Play Store build
See `store/PLAY_CONSOLE_CHECKLIST.md`. `eas build -p android --profile production` makes the .aab.

## Branding
- Logo, icons, splash, menu background and store graphics are generated by `store/make_brand_assets.py` (python3 + pillow, numpy, scipy). Re-run it to regenerate everything in `assets/` and `store/`.
- In-app intro: `SplashIntro` and main menu: `HomeScreen` in `App.js`.
- The Android package `com.noderra.rush3d`, the Expo slug `noderra-rush` and the internal save key are intentionally unchanged (they identify the app to Google Play / EAS and keep players' saved progress).
